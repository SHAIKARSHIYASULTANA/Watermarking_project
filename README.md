Tech Stack: OpenCV, NumPy, Image Processing, Cryptography Concepts, Python, Flask, HTML, CSS, JS. 
Developed a scalable and secure reversible watermarking system using Python and OpenCV for image privacy protection and secure watermark embedding.
Implemented Lucas series-based hybrid watermarking, achieving 100% watermark recovery, low extraction time (~0.135 sec), and preserved image quality with improved data confidentiality.
